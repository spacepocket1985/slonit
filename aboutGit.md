# Базовые команды Git 🐯.

## 1. Создать локальный репозиторий

`git init`

### 2. Клонирование репозитория

`git clone <url>`

### 3. Проверка статуса

`git status `

### 4. Добавление изменений в индекс

`git add <файл>`

### 5. Коммит изменений

`git commit -m "Сообщение коммита"`

### 6. Обновление удалённого репозитория

`git push origin <ветка>`

# Дополнительные команды Git🐸.

### 7. Rebase

`git rebase <ветка>`

> Переносит изменения из одной ветки на другую, делая историю более линейной.

### 8. Cherry-pick

`git cherry-pick <коммит>`

> Позволяет применить изменения из одного коммита к текущей ветке.

# Базовые флаги в Git 🐼.

### 1. -m

`git commit -m "Ваше сообщение" `

> Используется для добавления сообщения к коммиту.

### 2. -a

`git commit -a -m "Коммит изменений"`

> Автоматически индексирует все отслеживаемые файлы перед коммитом.

### 3. --force

`git push --force`

> Принудительно обновляет удалённую ветку.

### 4. -b

`git checkout -b new-feature`

> Создаёт новую ветку и переключается на неё.

### --interactive или -i

`git rebase -i HEAD~3`

> Позволяет интерактивно изменять коммиты во время rebase.

# Примеры использования управления коммитами 🐵.

### 1.Переименование последнего коммита

`git commit --amend -m "Новое сообщение коммита"`

#Пример:#
`git commit --amend -m "Исправлено описание коммита"`

### 2.Удаление последнего коммита

`git reset --hard HEAD~1`

#Пример:#
`git reset --hard HEAD~1`

### 3.Изменение промежуточного коммита

- Воспользуйтесь интерактивным #rebase#:
  `git reset --hard HEAD~1`
- Замените #pick# на #edit# для нужного коммита и сохраните файл.
- Измените ваши файлы, затем выполните:
  `git add <файл>  
git commit --amend  
git rebase --continue `


### 4. Удаление конкретного коммита

- Воспользуйтесь интерактивным #rebase#:
`git rebase -i HEAD~3`
- Удалите строку с коммитом, который хотите исключить, и сохраните файл.
